Services

- AI backend: http://localhost:8000

Normal browser flow
Browser -> Express gateway -> AI backend -> local Ollama

Source Lab flow
Browser -> Express /source/cache + /compression/* -> AI backend
Source -> chunk -> independently compressed cache -> source-aware retrieval -> Llama prompt

Offline MVP concept
- Keep only the active source/chat context in the local cache.
- Source chunks are losslessly compressed before cache storage.
- Retrieval decompresses only relevant chunks.
- Learner state remains separate from source knowledge.
- Llama is the local model used for chat testing.
